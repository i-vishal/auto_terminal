# auto_terminal
 
QGIS plugin for automatic FTTH terminal placement.
 
## Features
 
- Auto terminal naming (T1, T2, T3...)
- Reads Wirelimit Size
- Auto populates TRM_SIZE
- Auto populates START_COUN
- Auto populates TRM_COUNTS
 
## Requirements
 
- TERMINAL layer
- Wirelimit layer
 
## QGIS Version
 
3.22+
